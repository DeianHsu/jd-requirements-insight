## 1. 目标与边界

### 目标

让每个 P0-6 统计结论可追溯到对应 JD、公司、岗位、重要程度、原始要求名称和原文片段，使报告结论可核查。

### 非目标

- 不重新计算频率、不修改 P0-4 映射或 P0-2 原始抽取。
- 不在 Git 或公开报告中暴露完整私有 JD 正文。

### 验收标准

1. 每个频率结论可返回 JD、公司、岗位、重要程度、原始名称和原文片段。
2. 查询显式绑定归并批次，来源链完整且结果稳定排序。
3. 不泄露完整私有正文；不存在来源的异常有明确处理。
4. 具有从统计项到证据的端到端确定性测试并接入 P0-10 报告。

## 2. 接口与不变量

- 查询必须显式绑定统计所用归并批次，不能混合不同输入版本。
- 每条证据沿标准项 → 映射 → 要求实例 → 抽取记录 → JD 路径追溯。
- 输出只包含展示所需片段和元数据，不默认返回完整 JD。

## 3. 当前实现

- P0-7 专用查询模块尚未创建；现有数据基础已具备：P0-2 持久化 JD、抽取记录、职责、要求及其证据；P0-4 持久化归并批次、标准项、要求映射与原始要求外键。
