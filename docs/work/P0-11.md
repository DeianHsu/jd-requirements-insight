## 1. 目标与边界

### 目标

提供与最终实现一致的人类项目说明、架构图、运行步骤和演示入口，使他人能够复现“导入→抽取→原子化→要求归并与映射→评测→统计→追溯→报告”完整链路。

### 非目标

- 不为演示开发复杂前端、业务 API、Docker、CI/CD 或 Agent 编排框架。
- 不把真实 JD、人工标准答案、数据库、模型原始响应或个人信息放入文档和 Git。
- 不在 P0-10 完成前伪造完整流程或提前创建不存在的实现入口。

### 验收标准

1. README、架构图、运行步骤和演示脚本与当前代码、CLI 及 P0 状态一致。
2. 可使用公开或虚构数据复现完整 P0 链路，未实现功能不提供误导性路径。
3. 文档链接、格式、忽略规则和敏感信息检查通过。
4. P0-9 完成门禁通过。

## 2. 接口与不变量

- 文档中的命令、路径和模块职责必须在当前仓库中真实存在。
- README 只面向人类；仓库级 Agent 约束只位于 `AGENTS.md`。
- 演示使用可公开或虚构数据，不依赖提交私有材料。
