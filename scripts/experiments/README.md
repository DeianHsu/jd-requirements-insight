# experiments 目录说明

该目录只保存阶段实验和临时验收的编排代码，不保存可复用业务逻辑、私有数据或原始模型响应。

## 数据与输出

- 实验按P0放在对应的`p0_x/`子目录。
- 原始响应保存在`data/private/experiments/`，详细阶段报告按P0整理到`reports/P0-X/`。
- 真实LLM调用使用`--execute`，并显式选择数据库目标和输入范围。

实验脚本的开发与验收约束集中在[实验规则](../../docs/rules/experiments.md)。

## 目录职责

| 路径 | 职责 |
|---|---|
| `__init__.py` | 标记实验脚本包，导入时不执行操作。 |
| `p0_3/` | P0-3两段式抽取的真实调用与离线评测入口。 |
