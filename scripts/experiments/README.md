# experiments 目录说明

该目录只保存阶段实验和临时验收的编排代码，不保存可复用业务逻辑、私有数据或原始模型响应。

## 放置约定

- 每个实验放在对应的`p0_x/`子目录；不得在项目根目录新增临时Python脚本。
- 可复用逻辑进入`app/`并补自动化测试；实验脚本只解析参数、调用正式模块和保存结果。
- 原始响应写入`data/private/experiments/`；可公开的脱敏阶段报告写入`reports/experiments/`。
- 真实LLM调用必须要求显式`--execute`，数据库目标和输入范围也必须显式选择。
- 脚本必须提供中文模块说明、`main()`和`if __name__ == "__main__"`保护，导入时不得执行操作。

详细开发行为以根目录`AGENTS.md`的“实验性脚本与临时验收”章节为准。

## 目录职责

| 路径 | 职责 |
|---|---|
| `__init__.py` | 标记实验脚本包，导入时不执行操作。 |
| `p0_3/` | P0-3两段式抽取的真实调用与离线评测入口。 |
